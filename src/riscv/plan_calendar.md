## 交接与卡点

1. RTL 自测可复跑 → 交付配置和已知问题 → 专项/全量独立复验 → 缺陷修复与复跑 → 核验收。
2. 性能比较使用同一负载与明确配置，日志关联交付 commit；不得以模块级仿真代替核 CPI 结果。
3. 预计无法按 M1 收口时，按核计划的预测/转发预案说明降级范围，保留功能与证据验证。
4. 后续应用只记录核侧接口依赖；视觉、CNN 和 EXE 的任务去 [全局看板](../../plan.md#32-交付看板)。

## 完成条件

- 仓库内 tb 与脚本一键复跑；原始日志与实际版本可追溯。
