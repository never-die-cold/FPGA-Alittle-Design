# data —— 测试数据、黄金参考与指标汇总

对齐指南 §3.3.5.4：`data/` 承载"测试数据与参考结果"；原顶层 `metrics/` 已于 2026-09-14 并入本目录。

## 内容

- `metrics.csv`：指标汇总表（指标名称 / 类别 / 数值 / 单位 / 测量条件 / 测试次数 / 证据文件）
- `logs/`：原始日志（延迟分位数、任务闭环成功率等）
- `scripts/`：可重跑的测试脚本（须可在提交环境中重跑）
- `evidence/`：波形、示波器或逻辑分析仪截图
- `images/`：预处理流水线测试图样（规划）
- `models/`：CNN 权重（INT8 量化导出）与网络结构描述（规划）
- `golden/`：软件黄金参考输出（供仿真与上板比对，规划）

## 约定

- 「测量条件」必须写明：硬件型号、模型及数值精度、输入规格、软件版本、FPGA 时钟频率与功耗模式
- 禁止先写目标后凑数据：先测基线，再谈优化；数值与证据文件一一对应
- `metrics.csv` 使用 UTF-8 编码（Excel 打开时选 UTF-8 或走导入）
- 延迟与抖动报告分位数与最大值；吞吐采用持续运行结果，不用瞬时峰值
- 大文件（模型权重、视频）用下载脚本替代直接入库；报告中所有数据必须能追溯到本目录原始文件
- 演示级指标（直通对比/端到端帧延迟/动效帧率）随演示脚本一次采集，不单开测试轮次
