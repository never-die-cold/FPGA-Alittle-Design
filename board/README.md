## 板卡信息

- 板卡：PYNQ-Z2（XC7Z020-1CLG400C）× 1，**全队共用**
- 状态：✅ 2026-09-20 到货并完成上板验证（联网 / Jupyter / base overlay / 板载 LED）；SD 卡烧录完毕（PYNQ 镜像），已建立校园网 SSH 远程访问
