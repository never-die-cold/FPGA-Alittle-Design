# board/logs —— 上板实测记录（只追加，不删改）

> 上板实测是评分硬依据：每条记录必须可追溯到日期、硬件连接、bitstream/镜像版本与原始现象。
> 记录文件命名：`YYYY-MM-DD-英文主题.md`；一次上板一个文件；**不覆盖、不后补**。

## 记录模板

```markdown
# [YYYY-MM-DD] <主题，如 pynq-z2-smoke-onboard>

| 项 | 值 |
|:---|:---|
| 板卡 | PYNQ-Z2（全队共用）；序列号/标记：____ |
| 执行人 | ____（共用板使用时段已在群里报备：是/否） |
| 源码版本 | commit `______`（`git rev-parse --short HEAD`） |
| 构建产物 | bitstream 路径 + SHA256：____（或 vivado 构建 run 目录） |
| 硬件连接 | 供电：____；JTAG/串口：____；显示器/HDMI：____；网络：____ |
| 操作步骤 | 1) ____ 2) ____ 3) ____ |
| 现象/结果 | 实测现象（含失败与异常）；与预期的差异 |
| 证据 | 照片/视频/日志路径（`board/media/`、串口日志等） |
| 结论 | 通过 / 不通过；待办与后续动作 |

## 备注

- bitstream 版本必须写 commit hash；数据与报告引用本目录原始文件
- 失败记录同样要留（排查过程是评分材料，见 README 的协作记录规范）
- 每次使用共用板前后按 `board/README.md` 的约定群内报备
