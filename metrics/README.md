# metrics —— 指标报告与原始证据

按赛题指南 3.2.5.2 要求：所有实测指标汇总于 `metrics.csv`，每行一项指标；每项指标须附可重跑的原始日志与测试脚本。

## 目录

- `metrics.csv`：指标汇总表（表头遵循指南：指标名称 / 类别 / 数值 / 单位 / 测量条件 / 测试次数 / 时长 / 证据文件）
- `logs/`：原始日志（延迟分位数、任务闭环成功率等）
- `scripts/`：测试脚本（须可在提交环境中重跑）
- `evidence/`：波形、示波器或逻辑分析仪截图

## 约定

- 「测量条件」列必须写明：硬件型号、模型及数值精度、输入规格、软件版本、FPGA 时钟频率与功耗模式
- 禁止先写目标后凑数据：先测基线，再谈优化；数值与证据文件一一对应
- `metrics.csv` 使用 UTF-8 编码（Excel 打开时选 UTF-8 或走导入）
- 延迟与抖动报告分位数与最大值；吞吐采用持续运行结果，不用瞬时峰值
- 2026-09-11 增行：演示级指标（直通 vs 帧缓存架构对比、端到端帧延迟、演示动效帧率），对应命题升级方案 [docs/proposal_upgrade.md](../docs/proposal_upgrade.md) A 档；采集随演示脚本一次完成，不单开测试轮次
