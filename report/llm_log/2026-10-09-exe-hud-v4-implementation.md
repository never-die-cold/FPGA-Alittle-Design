## 1. 任务与初始提示词

用户用生图工具产出"高级感目标界面"，要求评估"为什么它更高级/能否达到/性能影响/能靠近
多少"。评估结论（更高级要素：应用外壳 > 排印 > 圆角/间距 > 光影 > 图标 > 细节密度；三档
可行性 A 现栈 75-85% / B 换 Qt 95% / C Web 100%）后，用户拍板 **A 档"性价比子集"**：
Pillow 真字体（含中文能力）+ 圆角面板 + 顶栏 + 检测对象列表 + 检查按钮；不换技术栈。

## 2. 实现（两步）

- **Step 1**：`hud_text.TextEngine`（Pillow 文本→RGBA 贴图缓存 + alpha 混合 + 变量字重
  `set_variation_by_name`）+ Inter 字体（OFL，raw.githubusercontent 被卡、改 jsDelivr 直连
  获取）+ 布局定稿图三轮评审（左上/左下对调、定位文字下沉、项目名改 EdgeSight）。
- **Step 2**：`hud.Hud` 渲染器（静态基座预渲染 + 固定形状 RGBA 贴图缓存 + 每帧动态层）+
  `preview.py` 状态字典化改造（endpoint / LOCAL DEMO / UVC-only 三种状态组装）+ RUN 按钮
  鼠标触发（`cv2.setMouseCallback`，与 `c` 键双通道）+ 字体随包（PyInstaller `--add-data`）
  + selftest 构建完整 Hud（等效验证打包字体寻径）+ 回归。

## 3. 失败现象（四个，逐个解决）

1. **对齐拉锯**：用户连续两轮反馈"左上/右上没对齐""EdgeSight 没对齐"、"REC 双横线太高"
   "按钮文字位置怪"。肉眼判断不可靠且来回拉扯。
2. **盒中心 ≠ 墨迹中心**：`--` 占位符按包围盒（bbox）垂直居中仍偏高——实测其盒高 13px，
   而墨迹（短横线本身）只占其中约 5px。
3. **药丸贴片合成错误**：初版把"黑底+文字"缓冲按 mask 替换进药丸 RGB 通道，导致所有
   绿/琥珀徽标只剩底色、文字全部消失。
4. **PyInstaller `--add-data` 相对路径坑**：指定 `--specpath` 后，相对源路径以 **spec 目录**
   为基准解析（报找不到 `sim/build/vision-client/src/vision_client/assets`）。

## 4. 纠错轨迹

| 轮次 | 喂回的信息 | 诊断 | 修改 | 验证 |
|:---|:---|:---|:---|:---|
| 1 | 用户两轮对齐反馈 | 手填坐标、各自按不同方式居中，无法保证 | 引入按文本盒高自动居中 + **编写像素探针脚本**（扫描画布行列求各元素墨迹范围）量化 | 探针：顶栏五元素中心 31.5–32.0（≤0.5px 差）、品牌块 849.5/849.0 |
| 2 | 探针显示 `--` 中心仍偏 15px | getbbox 盒 ≠ 墨迹（13px 盒里墨迹约 5px） | `draw_cy` 改为按**真实墨迹像素行范围**求垂直中心（对数字类无影响） | 探针：占位符中心 162.5 = 数字带中心 162.5 |
| 3 | 四态实渲染：徽标文字全消失 | 替换式合成把药丸底色盖掉 | `_chip` 重写：先铺底色 → 在其上画文字 → 套圆角 alpha | 四态图复查全部正常 |
| 4 | 构建报 assets 找不到（路径含 spec 目录） | `--specpath` 改变 `--add-data` 相对路径基准 | `--add-data` 改绝对路径（`Join-Path (Get-Location) ...`） | 打包三关 PASS；`_internal/assets/fonts/` 入包核对 |

## 5. 最终结论

HUD v4 实装完成：四态实渲染（02 端点 / 03 本地演示 / 04 等待 / 05 UVC）+ 打包三关
（selftest 含打包字体寻径验证；内容断言改为只看视频视口，防 RUN 按钮渐变混入绿色计数）+
回归 7/7 PASS。每帧 ~8-10ms（静态预渲染 + 贴图缓存），30fps 预算占用约 30%。

## 6. 经验沉淀

#skill候选
- **像素级 UI 对齐不靠肉眼，写探针**：把"看起来歪"翻译成"测得的数据"再动手修；
  短横线/符号/标点类占位符按 **墨迹中心** 而非包围盒中心对齐（盒 ≠ 墨迹）。
- **贴图合成顺序**：替换式合成（按 mask 覆盖 RGB）会丢掉底层内容——"先铺底、再作画、
  最后套 alpha"是安全顺序。
- **PyInstaller 打包数据**：`--specpath` 会把 `--add-data` 相对源路径的解析基准改到 spec
  目录；数据源路径一律绝对化。
- **"AI 参考图 → 性价比子集"的取舍方法**：先按影响面对元素排序（外壳/排印 ≫ 光影/图标），
  把可得的 70-85% 先落地，明确不做清单（导航空壳/真阴影/换栈），避免为最后 15% 挤压功能开发。
