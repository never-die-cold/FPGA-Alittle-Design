## 6. 经验沉淀

- 触发条件：跨模块文档修改容易滞留在某个功能分支的工作区，长期不提交会随分支切换丢失或混入不相干 PR。
- 排查步骤：
  1. 先跑"引用一致性体检"：文档承诺的 tag / 文件 / 链接是否真实存在（本例 tag 缺失、README 链接未入库文件）；
  2. 生成物与归档分离：证据只留一份（`data/logs/`），其余输出目录整体 ignore；
  3. 流程规则只写在 plan.md 一处，日历与 README 用链接引用，避免三处口径漂移。
- 适用范围：换项目仍成立；"文档承诺 ≠ 事实"是仓库卫生的高频欠债。 #skill候选
