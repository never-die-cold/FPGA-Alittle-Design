## 1. 任务与初始提示词

> "在网上搜索一下往年这个比赛的AMD赛道的获奖作品信息，并整理一下"

目标：为 2026 参赛（AMD 自主选题·初级组）收集往届获奖作品、赛道规则与可借鉴资源。

## 2. 模型第一版方案

直接走通用搜索引擎：Bing 关键词搜索、Sogou、DuckDuckGo HTML 版，并直接抓官方站 `fpgachina.cn`。

## 3. 失败现象（真实偏差）

1. **Bing 返回无关结果**：查询"全国大学生嵌入式芯片与系统设计竞赛 FPGA AMD 获奖名单"，返回的却是 `127.0.0.1:8080 怎么打开` 等完全无关条目（疑似反爬/降级页面）；`site:fpgachina.cn` 查询同样返回上海大学登录页。
2. **Sogou 要求验证码**、**DuckDuckGo HTML 版直接连接失败**。
3. **官方网站不可用**：`fpgachina.cn` 为 JS 渲染，抓取仅得到一张 banner，拿不到获奖名单；下载中心链接在第三方资料中才找到。
4. 综上：**第一版方案（通用搜索引擎）在该网络环境下不可靠**，无法产出可信结果。

## 4. 纠错轨迹

| 轮次 | 喂回的信息 | 模型诊断 | 修改内容 | 验证结果 |
|:---|:---|:---|:---|:---|
| 1 | Bing/搜狗/DDG 均失败；官网无内容 | 中文赛事情报改用**代码托管平台 API**：学生获奖作品有开源习惯，GitHub 搜索可直击作品仓库 | 用已认证的 `gh api search/repositories` 搜索关键词 | ✅ 命中 `hlstrack2025_*`（AMD 命题赛道）、`fpgachina2025_*` 等大量仓库 |

## 5. 最终结论

产出 `docs/amd_track_awards.md`（并在 `docs/resources.md` §11 挂链接），包含：

- **2025 AMD 命题式基础赛道（HLS）国奖作品**：国一 `hlstrack2025_40562`（三算子 + 决赛 SR-UKF）、国二实时频谱仪/音频分析仪等 10+ 仓库，含初赛得分与技术路线
- **自主选题线索**：3DGS-SLAM（ZCU104）、肺结节检测等；结论：自主选题开源少，**本项目自研 RISC-V 核属差异化方向**
- **其他杯赛高相关作品**：2024 易灵思国一无极缩放（对标模块二）、2025 安路国一 OV5640+UDP+HDMI 系统
- **2026 AMD 自主选题官方规则摘要**：初级组 PYNQ 推荐、评分权重（创新 30/性能 20/完整 20/协作 15/文档 15）、推荐目录结构、Vivado 2025.2 合规
- **高价值资源**：决赛 Verilog 上机真题（2019–2025，MrYanYe 仓库）、2026 选题指南 139 页转录（Qian-Sai）
- **诚实边界**：奖项来自作者自述，未经官方核验；官方名单站反爬未能获取，文档已注明

**验证方式**：文档中的仓库链接逐一来自 GitHub API 返回；2026 规则要点来自第三方逐页转录原文（可用官方 PDF 复核）。

## 6. 经验沉淀

- 触发条件：需要调研中文竞赛/开源项目情报，但搜索引擎不可用或返回垃圾结果 #skill候选
- 排查步骤：
  1. 中文技术竞赛的获奖作品情报，优先用 **GitHub/Gitee API 搜索**（学生开源习惯 + 关键词如赛道代码 `hlstrack2025`），而不是死磕搜索引擎
  2. 用脚本（Python）调 API 并把结果写 UTF-8 文件，避免 PowerShell 5.1 的编码/JSON 管道坑
  3. 拿到仓库清单后，批量抓 README 提取"奖项 + 技术栈 + 量化成绩"，比逐个人工点开快得多
  4. 官方站点抓不动时，找**第三方结构化整理**（如赛事指南转录仓库）作为线索，并在文档中标注需官方复核
  5. 引用奖项必须标注"作者自述/待核验"，不把二手信息写成官方结论
- 适用范围：换赛事、换技术方向、换网络环境均成立
