## 6. 经验沉淀

- 触发条件：长期阻塞项（缺件 / issue）解除后，仓库仍残留"顺延 / 等待"表述 #skill候选
- 排查步骤：
  1. 全库 grep 阻塞项编号与关键词（"未到货 / 顺延 / 待 XXX"），逐条判断是否仍成立
  2. 状态类文档（清单 / 排期 / 任务卡）改现状；历史记录（llm_log）只追加更新指针，不改写
  3. 资源稀缺（如 1 块板 3 人共用）时，把使用约定写进资源所属目录（`board/README.md`），不靠口头约定
- 适用范围（换题目 / 换板卡是否成立）：成立；任何"阻塞解除"类事件都适用
