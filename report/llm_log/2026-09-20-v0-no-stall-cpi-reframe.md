## 3. 失败现象（真实偏差）

契约核对发现**任务卡预期与 v0 契约相反**，且连带暴露 README 指标不可达：

1. `design_v0.md` §2.2 原文：v0 **无 RAW 停顿**——指令 N 拍末写回，N+1 下一拍译码读到新值；`lw` 经异步数据 RAM 同拍写回，无 load-use 停顿；结论 **"v0 的 CPI ≈ 1 + 分支代价"**
2. RTL 佐证：`core_top.v:18` `stall = 1'b0`（v0 无多拍指令）；`regfile.v` 组合读、时钟沿写；`if_stage.v` 仅 `flush_q` 注入分支气泡
3. 因此 v0 数据冒险序列的预期是：**结果正确 + 数据气泡 0**；唯一气泡来源是 taken 分支/跳转（§2.3，每次恰 1 拍）
4. **连带问题**：README 指标行"CPI 基线=两级流水实测值，目标降低 ≥25%"与 `plan.md` §4.3"CPI 相对 v0 基线降低 ≥25%"数学上不可达——v0 稳态已是 1 指令/拍；v1 三级稳态吞吐同为 1/拍，且额外有 load-use 停顿，CPI 只会 ≥ v0

## 5. 最终结论

- **转发专项 tb 判据（v0 对照档）**：程序结果正确；R 型连读与 lw→add 序列数据气泡 = 0；taken 分支/跳转各 1 拍气泡（计数与静态分析一致）
- **CPI 指标新口径**：主指标 = v1+转发 vs v1 无转发（同三级核）降 ≥25%；v0 CPI 实测作为"两级基线参考"入档，不再承担降幅基线
- **后续动作**：Part B 需产出 v1 无转发对照档（转发逻辑可配置关闭或临时回退版）；Part C 最终数据表档位为 v0 / v1 无转发 / v1+转发 / v1+转发+预测
- 125 MHz 上板时钟方案仍待拍板（`design_v0.md` §10 待办），与本次口径问题无关

## 6. 经验沉淀

- 触发条件：为"优化前/后"设计对照测试时，先核对基线版本的契约行为 #skill候选
- 排查步骤：
  1. 写测试预期前先读基线版本的架构契约（拍序/冒险/停顿章节）+ 对应 RTL 关键信号（本例 `stall` 硬编码）
  2. 检查指标定义中的"基线"和"对比对象"是否同一对象（本例一个说两级流水、一个说同核无优化版，自相矛盾）
  3. 基线指标在数学上不可达时，及时重定义并全库同步（README/plan/llm_log），不要等验收时才发现
- 适用范围（换题目/换板卡是否成立）：成立；任何"分阶段优化 + 量化对比"的项目都适用
