## 2. 模型第一版方案

- **恢复除法（32 拍）**：每拍把被除数下一位接到余数末尾——`remainder_shift = {remainder_work[31:0], quotient_work[31]}`；与 `divisor_r` 比较，`>=` 则减去除数、本拍商位记 1，否则记 0；商寄存器左移并入新商位（`quotient_next = {quotient_work[30:0], quotient_bit}`）。
- **符号分离保存**：`quotient_neg = div_signed && (a[31]^b[31])`（商 = 两操作数符号异或）；`remainder_neg = div_signed && a[31]`（余数始终跟随被除数）。
- **边界**：`divisor_r==0` 时 `final_quotient` 优先强制 `32'hFFFF_FFFF`；`INT_MIN / -1` 由「取绝对值算 + 恢复符号」自然回绕为 `0x8000_0000`。
- 完成后按 `op_r[1]` 选择商或余数写出 `result`。

## 6. 经验沉淀

- 触发条件：给两级流水核补多拍恢复除法；团队多为 Verilog 新手。
- 排查步骤：
  1. 恢复除法一句话：「移位取位 → 与除数比较 → 够大就减并记 1，否则记 0」，32 拍后得商与余数；
  2. 符号规律：**商**符号 = 两操作数异或，**余数**符号 = 被除数（不能都按异或处理）；
  3. 除零要**显式短路**（商全 1、余数=被除数），不能依赖「比较恒成立商自然为全 1」——被除数为负时恢复符号会把它破坏；
  4. 结果定稿用组合的 `*_next`/`*_sum` 值，避开非阻塞赋值读到本拍旧值的坑。
- 适用范围：换模块、换板卡均成立；移位加减的乘除迭代结构可复用。 #skill候选
