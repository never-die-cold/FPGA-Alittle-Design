## 2. 模型第一版方案

按旧有认知（Vivado WebPACK / ML Standard 免费、XC7Z020 在免费范围内）给出下载与安装步骤，默认选最新 2026.1。

## 3. 失败现象（真实偏差）

查官方下载页与授权页后发现旧认知不再成立：

1. **2026.1 起 Vivado 改为 tiered 授权**（BASIC / CORE / PRO / ENTERPRISE / GOLD）：免费档从 ML Standard 变为 **BASIC（$0）**，且附加两个对比赛不利的条件——**需要每年续期 license**、**Simulation 仅 "Limited Features"**；Vitis 后端流程也需有效 tiered license
2. 硬件约束：本机系统盘剩余空间不足（实测约 39 GB，低于 60 GB 需求），原步骤未提前校验磁盘

## 4. 纠错轨迹

| 轮次 | 喂回的信息 | 模型诊断 | 修改内容 | 验证结果 |
|:---|:---|:---|:---|:---|
| 1 | 官方 licensing 页（BASIC 条款与器件覆盖表） | 2026.1 免费档对仿真有限制，不适合以 XSim 测试驱动的验证流 | 版本决策改为 **2025.2（ML Standard）**；2026.1 BASIC 列为备选并附限制说明 | ✅ 交付版本对比表 |
| 2 | 本机磁盘余量与路径规范 | 安装盘未校验，系统盘空间不足 | 安装要求改为"非系统盘、预留 ≥ 60 GB、路径纯英文无空格"，记录不写具体盘符 | ✅ 验收清单更新 |

## 5. 最终结论

- **选 Vivado 2025.2（ML Standard，免费）**：7 系列无需 license 文件、仿真功能完整、即装即用；2026.1 BASIC 作为备选（需年度续期、仿真受限）
- 安装要点：非系统盘 + ≥ 60 GB 空闲 + 纯英文无空格路径；组件仅 Vivado + Zynq-7000 + Cable Drivers；验收 = 版本号确认 + `xc7z020clg400-1` 综合无报错 + XSim 计数器波形跑通
- 结论已以评论形式补到 GitHub issue #2，供队友直接执行
