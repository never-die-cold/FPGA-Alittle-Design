# report —— 设计报告与协作记录

## 目录

- `llm_log/`：大模型协作记录（规范见 [llm_log/README.md](llm_log/README.md)，模板见 [llm_log/template.md](llm_log/template.md)）
- 设计报告：按 AMD 赛道 3.3.5.3 要求组织，期末成稿

## 设计报告大纲（按赛道要求）

1. 选题背景与创新点：为什么选这个题目，解决什么实际问题，前人做过什么
2. 设计原理与功能框图
3. 软硬件划分依据与接口设计
4. 优化过程，含优化前后的性能与资源对比表
5. 大模型协作记录：提示词、模型回答、自我纠错轨迹、智能体工作流设计
6. 技能包的提炼过程：从哪些失败或观察中总结、如何验证有效、边界如何确定
7. 复现说明：可供他人从零开始完整执行的操作步骤

## 约定

- 报告数据必须与 `data/metrics.csv` 一致，引用原始日志
- 波形图用 Wavedrom 或仿真截图，截图归档到本目录
