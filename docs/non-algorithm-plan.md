1. P0：逐项整合 `95b853d`，更新主计划和核计划；完成 PYNQ 开机加载与可控 HDMI 恢复入口。服务“加载成功”与“视频健康”分开报告。

3. P2：先以确定性目标列表实现类别计数、工单比较、缺件/多余件/错料/复检和幂等入账，再接入已有结果；完成批次、截图、CSV/JSON、安装与回退材料。
4. 真实图像获取与模块三数据接口未冻结前，不假定 `cop_*`/ILA 可供 PS 读取像素，不新增未经验证的整帧 DDR 通路，也不占用协处理器保留地址。
