## 判定口径（避免伪通过）

1. 退出码 0 **且** 日志里有该用例的 `PASS:` 行；两者缺一不算。
2. 负向用例必须能"去掉修复就 FAIL"，否则只是没测到（见 `cop_top` 的 done 保护拍对照）。
3. 冒烟 PASS ≠ 完整验证；离板 PASS ≠ 板端通过；仿真 ≠ 综合。
4. 任何"已验证"都能由仓库内 tb/脚本一键复现，临时文件不算证据。
