## 2. 升级依据（对着评分权重找缺口）

2026 AMD 自主选题赛道评分权重：**创新性与应用价值 30** / 性能与资源优化效果 20 / 功能正确性与设计完整性 20 / 大模型协作与技能包 15 / 文档质量与可复现性 15。

原命题（三模块并列）的短板：模块"拼盘感"偏强、应用故事泛化、演示形态偏静态。往届获奖作品验证的高分范式：**单点打透 + 全部指标可测 + 演示动效 + 闭环故事**。

## 4. 升级后的命题定位（注册名不变，内部叙事 v2）

> EdgeSight：一颗把"看清 → 看懂 → 跟踪"装进片内的边缘视觉智能 SoC——
> **自研三级流水 RISC-V 核**统一调度，**参数化视觉直通流水线**零帧缓存依赖（逐像素延迟固定可测），**INT8 推理协处理器**与 ARM 软件基线**同屏一键切换对比**；
> PS 侧 Jupyter 作为控制中心：实时调参、指标实时曲线、OSD 动效演示——作品形态是"片上可交互视觉分析仪"，而不是三个模块的拼盘。

## 5. 组合阶梯

### A 档：叙事 + 演示级（必做，随 M2/M3 内嵌，复用既有硬件）

| 项 | 内容 | 借鉴来源 |
|:---:|:---|:---|
| A1 | 预处理链路**参数化**：AXI-Lite 动态组合灰度/滤波/缩放/边缘（含开关与参数） | Ultra-Vision"一套算法统一三种插值" |
| A2 | **直通 vs 帧缓存**架构对比：给延迟/带宽/资源三列实测数据 | Ultra-Vision 创新点 1（免 DDR 直出） |
| A3 | **软/硬推理一键切换**：同一网络 ARM 软件版 vs 协处理器版，同屏对比延迟 | 国一 40562 soft/hardware 双 notebook |
| A4 | **演示动效**：OSD/ROI 框动画、Jupyter 调参面板实时曲线 | Ultra-Vision 动画 + 国二 PyQt/Web 可视化 |
| A5 | 指标表补**演示级指标**：逐像素固定延迟、端到端帧延迟、动效帧率 | Ultra-Vision 指标颗粒度 |

### B 档：检测-跟踪闭环（stretch，10/25–11/4 窗口）

- 内容：CNN 检测 → **自研 RISC-V 核跑轻量跟踪**（质心/简化定点滤波）→ OSD 闭环显示
- 前提：L3 保底验收完成；**无新硬件**；随时可砍（issue 跟踪）
- 对标：国一 40562 的"检测→跟踪"决赛延伸结构

### C 档：EdgePilot 云台伺服（L4，预采购不承诺）

- 方案全文见 [`docs/idea1.md`](idea1.md)（视觉引导控制 SoC：感知-决策-执行，像素到 PWM）
- **只预采购**舵机/云台支架（低价值风险）；10 月中旬进度超前才启动集成
- 阶梯关系（在原 L1/L2/L3 之上扩展，沿用 idea1 定义）：

| 版本 | 内容 | 状态 |
|:---|:---|:---|
| L1/L2/L3 | EdgeSight 原版三级降级策略（README） | 不变 |
| **L3.5（stretch）** | L3 + 检测-跟踪闭环演示 | B 档 |
| **L4（冲奖）** | EdgePilot 云台伺服全链路 | C 档，预采购不承诺 |

## 6. 演示剧本（现场 3 分钟流程草案）

1. 开场：Jupyter 控制中心，指标实时曲线已在跑（先亮"仪器"形态）
2. 直通链路：面板实时调参（滤波核/缩放/ROI），画面即时响应 + OSD 动效
3. 软硬切换：同一网络"ARM 软件推理 ↔ 协处理器推理"一键切换，同屏延迟对比
4. 闭环（若 B 完成）：检测框 → 跟踪轨迹 → OSD 动效
5. 收尾：metrics 汇总表 + "先测基线再谈优化"的对照数据

## 8. 风险与砍法

- **B 砍法**：退回 A（OSD 静态叠加），演示剧本第 4 步删去。
- **C 砍法**：云台不集成，EdgeSight 完整交付（L3），采购件转为赛后实验。
- **指标采集增量风险**：演示级指标随演示脚本一次性自动采集（`metrics/scripts/`），不单开测试轮次。
- 若 M3 进度滞后：先砍 B/C，A 档的 A2/A3 优先级最高（对应创新性与性能两项评分）。
