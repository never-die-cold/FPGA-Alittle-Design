# 照片拍摄方案（实验室版，2026-11-03）

> 用途三处：**技术文档配图**（2–3 张）、**A1 海报**（1 张主图 + 1 张界面图，需高分辨率）、**答辩与提交材料**（全景、细节、团队）。
> 与视频共用同一次实验室布景，视频拍完顺带拍照片，总耗时约 40 分钟。
> 命名：`photo-<用途>-<序号>.<ext>`，原图统一放仓外 `D:\Desktop\contests\2026fpga\照片-20261103\`，入库件按 repo-hygiene 压缩后放 `docs/tech-report/figures/`。

## 一、通用要求

| 项 | 要求 |
|:---|:---|
| 器材 | 手机主摄（≥4000 像素长边）或相机；**别用超广角**（边缘畸变会让板卡变形）；用主摄或 2× 长焦 |
| 格式 | HEIC/RAW 或最高质量 JPEG；**关闭美颜、HDR 自动、AI 增强**（会涂抹文字与丝印） |
| 曝光 | 点击板卡区域锁定对焦与曝光；画面直方图不溢出（白色亚克力易过曝） |
| 构图 | 横构图为主（文档与海报都是横向版面）；板卡四边留 8–10% 余量便于裁切 |
| 光线 | LED 面光 45° 主光 + 白纸/白泡沫板做补光；**避免顶灯直射亚克力**（反光带毁片）；避免闪光灯直打 |
| 背景 | 白墙或深灰桌布；画面内不得出现他人、杂物、其他作品、水杯、纸质资料 |
| 稳定 | 用三脚架或把手机靠在书架/箱子上；室内光下快门 ≥1/60 更稳 |
| 清洁 | 拍前擦板卡（镜头布）、擦桌面、整理线材；镜头本身也要擦 |

## 二、必拍清单

### P1 整机工位全景（技术文档图 3-1 / 海报主图 / 答辩首页）

- 机位：三脚架，与桌面约 30° 俯角，距离 1.2–1.5 m，横构图
- 画面内容（自下而上）：笔记本屏幕（显示网页端界面）→ 桌面 → 亚克力支架上的 PYNQ-Z2 → 顶部树莓派相机 → 背景设备柜
- 要求：屏幕内容清晰可辨（别让屏幕过曝成白块）；线材走背面不可见；三人中的一个可侧身站在画面边缘作比例参照
- 变体：① 纯设备（无人）② 一人操作（手在键盘上）各拍 5 张
- 版式预留：左侧或上方留出 1/3 空白给标题文字

### P2 板卡特写（技术文档图 3-2 / 海报）

- 机位：垂直俯拍，距离 40–50 cm，**横构图**
- 要求：PYNQ-Z2 完整入画，四边留余量；HDMI 输入/输出、网口、USB 接口与丝印清晰可读；亚克力支架可见但不出画
- **分辨率要求（海报 300 dpi）**：板卡在画幅中占宽 ≥1800 像素
- 变体：① 正俯拍（文档用）② 45° 斜俯（海报用，更有立体感）各 5 张

### P3 相机与工件俯拍（技术文档图 2-2 / 海报）

- 机位：垂直俯拍工件区，画面框住 A3 幅面
- 内容：螺栓/螺母/垫圈自然散布 + 画面边缘露出树莓派相机或支架一角（表明是相机视角）
- 要求：工件不重叠、不遮挡；阴影柔和（面光偏侧）；深灰桌布衬托
- 变体：① 零件散布 ② 手正在放零件（手入画但不停留）各 3 张

### P4 网页端界面截图（技术文档图 3-3 / 海报界面图）

- 不是拍照，是**截屏**：浏览器 F11 全屏 + 系统截图，分辨率 1920×1080 或更高
- 状态要求（按优先级）：
  1. **有框 + 日志有判定的一轮**（最有信息量）
  2. 连接采集卡后、结果未到的"识别中"状态（备用）
- 必须显示：板端 session、config、ROUND、REC、目标卡、日志中的 RECHECK/low_score
- 注意：截图前把浏览器缩放设为 100%，关闭书签栏；不要用手机拍屏
- 需要 2 张：① 全屏 ② 右侧识别范围区局部放大（海报用）

### P5 细节特写（答辩与花絮，选拍）

| 内容 | 用途 |
|:---|:---|
| 采集卡 + USB 线 | 说明链路 |
| 板卡指示灯亮起（电源/DONE） | 证明"在跑" |
| 树莓派相机镜头与 CSI 排线 | 说明视频源 |
| 手握零件对镜头 | 海报装饰/开场 |
| 三人围看屏幕讨论 | 团队照 |

### P6 团队照（提交材料）

- 机位：与 P1 同机位，三人站工位后方
- 着装统一（白大褂）；表情自然，不看镜头也可以（看屏幕更真实）
- 横构图，左右留出文字空间；拍 8–10 张选 1

## 三、拍摄顺序（省时）

1. 先拍 **P2 板卡特写**（此时桌面最干净）
2. 再拍 **P3 工件俯拍**（摆好零件，顺手就是视频 S3 的素材）
3. 拍 **P1 全景** + **P6 团队照**（人到位时一起拍）
4. 开板端跑一轮，**截 P4 界面**（与视频 S4/S5 同期）
5. 最后拍 **P5 细节**（随意性强，剩余时间补）

## 四、质检清单（当场逐张过）

- [ ] 焦点在板卡丝印/屏幕上，不在前景
- [ ] 无频闪横纹、无闪光反光斑、无亚克力反光带切过板卡
- [ ] 屏幕内容可读，不是一片白
- [ ] 背景无杂物、无他人、无其他作品
- [ ] 线材不横穿画面主体
- [ ] 板卡四边完整、留裁切余量
- [ ] 同一机位至少 3 张备选（手抖/闭眼/对焦跑）
