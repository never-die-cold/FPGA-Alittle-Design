## 阶段 0 · 出发前（宿舍/工位，40 分钟）

- [ ] **技术文档定稿**：确认 `docs/tech-report/EdgeSight-技术文档-初版.docx` 是最终版（含手改心得）
- [ ] **抄数字卡**（见 §A），打印或存手机；片中所有数字以此为准，不许现场估
- [ ] **准备器材**：三脚架×2（或悬臂）、手机×2（一台拍 A，一台拍 B/微距）、充电宝、扎带、深灰桌布、LED 面光、白大褂（3 件）、干净抹布
- [ ] **准备零件**：螺栓 ≥6、螺母 ≥6、垫圈 ≥6（干净无油污），装在托盘里带去
- [ ] **确认板端可用**：实验室网络下板端 IP（当前记录 `192.168.50.99`）能 ping 通，8765 端口有服务；不通则先找 NC 恢复
- [ ] 笔记本：关闭通知/专注助手、关桌面图标、浏览器只留一个标签页

## 阶段 1 · 到场布置（40 分钟）

- [ ] 选靠墙工位，清空背景：移走其他板卡、纸箱、水杯、个人物品
- [ ] 铺深灰桌布；PYNQ-Z2 装亚克力架居中；树莓派相机架在正上方约 60 cm，光轴垂直台面
- [ ] 走线：HDMI 进板卡、HDMI 出到采集卡、采集卡 USB 到笔记本、网线到板卡——**全部从支架背面走，扎带收拢**
- [ ] 开 LED 面光 45°；关掉正上方直射灯（若可关）
- [ ] 三人换白大褂；整理发型与工牌（若有）
- [ ] 试拍 10 秒：检查有无频闪横纹、反光带；有则快门改 1/100

## 阶段 2 · 板端与网页端就绪（30 分钟）

- [ ] 板端启动产品服务（以板端部署为准）：
      `cop_product_service.py --package <r6 包> --root /home/xilinx/cop-live-video-20261103 --order 3,3,3 --background-mode local --color-threshold 25 --min-score .8`
- [ ] 笔记本启动网页服务：`python src/web_client/serve.py --endpoint http://192.168.50.99:8765`
- [ ] 浏览器打开 `http://127.0.0.1:8000`，确认 SYSTEM 显示板端 session 与 config
- [ ] **只留这一个页面**（F01：第二个页面会抢配置导致断开）
- [ ] 选 `USB Video (345f:2109)` → 点「连接采集卡」→ 画面出现 1280×720
- [ ] 按一次 RUN INSPECTION 试轮：确认结果到达、出框、日志有判定
- [ ] 若出现 TASK_ERROR / DMA 超时：停服务 → 换新 `--root` 目录重开 → 重连采集卡 → 再试一轮

## 阶段 3 · 录屏（40 分钟，OBS）

- [ ] OBS：1080p60、x264 CBR 20000kbps、MP4、静音、只录浏览器窗口（不是全屏）
- [ ] 按 README §4 顺序录，**每段单独录 2–3 遍**，文件命名 `S4-1.mp4`、`S5-2.mp4`：

| 段 | 操作序列 | 要点 |
|:---|:---|:---|
| S4 | 刷新页 → 选设备 → 连接采集卡 → 等框出现 → 停 8s | 框出现后立刻录，4.5 秒会过期；连录 3 遍 |
| S5 | 点 RUN INSPECTION → 录完三态 → 结果到达 → 停 5s | 按钮三态要完整；日志里 RECHECK/low_score 要可读 |
| S6 | 结果到达后**什么都不点**，等 5–6 秒看撤框 | 一镜到底，不能剪；这是全片最有说服力的镜头 |
| S7 | 点 RUN 一轮 → 批次卡 REC+1 → 点 CSV 导出 → 切 Excel 打开 | Excel 打开 CSV 时录 5 秒；标题行要能看清 |

- [ ] 每段录完立即回放检查：框是否与工件对齐、日志是否清楚、有无红字错误
