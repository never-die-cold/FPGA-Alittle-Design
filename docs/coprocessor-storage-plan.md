# CNN 协处理器片上存储方案

> 状态：**PLAN / UNVERIFIED**。只使用 C02 的形状与排布、32,592×INT8 权重、
> 147×INT32 折叠 bias、128 MAC/拍和 x7z020 上限（220 DSP、140 BRAM36，约 630 KiB）；
> 不表示实体 BRAM、综合或板上路径已经实现。

## 逐层容量与放置

`A` 为 32 KiB 特征 bank，`B` 为 16 KiB 特征 bank，`R0/R1` 为两个 4 KiB ROI bank，
`W0..W15` 为 16 路权重 bank，`P` 为参数/小 scratch bank。权重地址单位是 128 B O16×I8 块。

| 层 | 输入容量 / bank | 权重 raw→补齐 / W 块地址 | bias raw | 输出容量 / bank | 缓冲边界 |
|:---|---:|---:|---:|---:|:---|
| conv1 | 4,096 B / R0或R1 | 144→1,152 B / 0–8 | 16×4=64 B | 16,384 B / B | 完层后 R→B |
| conv2 | 16,384 B / B | 4,608→4,608 B / 9–44 | 32×4=128 B | 32,768 B / A | 完层后 B→A |
| conv3 | 32,768 B / A | 9,216→9,216 B / 45–116 | 32×4=128 B | 8,192 B / B | 完层后 A→B |
| conv4 | 8,192 B / B | 18,432→18,432 B / 117–260 | 64×4=256 B | 16,384 B / A | 完层后 B→A |
| GAP | 16,384 B / A | 0 | 0 | 64 B / P scratch | 完层后提交 64 B |
| FC | 64 B / P scratch | 192→1,024 B / 261–268 | 3×4=12 B | 3 B logits / 结果寄存器 | 最后提交结果 |
| 合计 | ROI 8,192 B；A+B 49,152 B | 32,592→34,432 B / 269 块 | 147×4=588 B | GAP+结果 67 B | 层间 ping-pong |

补齐只来自 C02 固定排布：conv1 的输入通道补到 8，FC 输出补到 16；不存在的 lane 权重为 0。
实际 payload 仍以 manifest 的 64 B 对齐 offset/length 为准，不能由本表反推 DMA 文件布局。

## BRAM 组织、端口与供数

按 RAMB36 的 64-bit 有效数据、512 深度（4 KiB/块）规划；所有读为同步 1 拍。

| 对象 | 容量 | BRAM36 | 物理宽度 | 每个 MAC 发射拍同时供给 | 策略 |
|:---|---:|---:|:---|---:|:---|
| ROI R0/R1 | 2×4,096 B | 2 | 各 64 bit | 选中 bank 8 B | 双缓冲：DMA 写一块、conv1 读另一块 |
| 特征 A | 32,768 B | 8 | 2 路×64 bit、各深度级联 | 读 8 B；输出完成拍可写 16 B | 层级 ping-pong，非逐 tile 覆盖 |
| 特征 B | 16,384 B | 4 | 2 路×64 bit、各深度级联 | 读 8 B；输出完成拍可写 16 B | 与 A 角色交替 |
| 权重 W0..W15 | 34,432 B | 16 | 16 路×64 bit | **128 B** | 全权重常驻；每路对应一个 out_lane |
| 参数/小 scratch P | 约 1.5 KiB | 1 | 64 bit | MAC 拍不直读；先缓存到寄存器 | 单缓冲，任务期间只读 |
| 合计 | 约 93 KiB 有效数据 | **31** | — | 输入8 B+权重128 B=136 B/发射拍 | 31/140=22.1% BRAM36 |

输出的 16 个 INT8 通道是 16 B：目标特征 bank 的两路 64-bit 同拍各写一个 C8 word。
参数在每个 O16 输出块开始前预取：16 个 bias 用 8 拍、16 个 multiplier 用 8 拍、
16 个 shift 用 2 拍，随后从寄存器复用；因此不与 136 B/拍的 MAC 供数争端口。

## 编址、延迟补偿与双缓冲边界

- 权重：`group=((((out_block*KH+ky)*KW+kx)*in_blocks)+in_block)`；Wn 的 64-bit 字
  保存该 group 的 `out_lane=n`、8 个连续 `in_lane`。层基址依次为 0/9/45/117/261。
- 读延迟：在 MAC 发射拍 `k` 的前一拍 `k-1` 同时给特征和 16 路权重地址；把 valid、padding、
  output 坐标和尾块 mask 同样延迟 1 拍，在 `k` 才送 128 MAC。首地址只灌流水，不得计 MAC。
- 双缓冲：ROI 只在任务边界交换 R0/R1；中间结果只在整层 DONE 后交换 A/B 角色。
  conv1→B、conv2→A、conv3→B、conv4→A；禁止边算边覆盖仍被本层读取的 bank。

**OPEN-K2-1**：16×64 权重银行和 A/B 双 64-bit 写口是满足带宽的保守物理规划；BRAM 推断数量、
端口模式与布线时序必须由 Windows 侧 Vivado 报告确认，未确认前不得写“已实现”。
