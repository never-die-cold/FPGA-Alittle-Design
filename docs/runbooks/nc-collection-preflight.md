# NC采集前准备：无需板卡的部分

2026-10-14；沿用[采集规程](fastener-data-collection-protocol.md)和[WC交接包](fastener-collection-handoff.md)，不重复冻结机位或数据量。
本单准备物品与登记方式；尚无正式工位采集数据。示例编号不是已有实物，填实物库存后才分配。

## 桌面与实物准备

| 项目 | NC现在可做 | 当前记录 |
|---|---|---|
| 螺栓/螺母/垫圈 | 清点个体，按尺寸/外观/材质区分；标签贴收纳格，不贴零件 | 未清点 |
| 个体隔离 | 每类预留只进test的独立个体；其余分配train/val，不能为凑比例复用test | 未分配 |
| 标尺与支架 | 找到毫米刻度尺、固定支架、定位贴和水平摆放区 | 未核对实物 |
| 背景与布光 | 准备dark/gray/wood候选和漫射材料，标记L0–L3布置 | 未核对实物 |
| 场景道具 | 正常6件、缺/多/错料、空场景、10/11/16/17件、触边/接触/阴影/反光 | 未核对数量 |
| 存储与交接 | 预留原帧/证据空间、第二份备份；同会话即时交WC，不等整批 | 未实测余量/备份 |

|---|---|---|---|---|---|

## 会话与交付

1. 会话整体只进一个split；预留独立test会话/个体，test不用于量化校准或参数调优。
2. session使用`sess-YYYYMMDD-HHMM-l0..l3-bg`小写编码，记录light列为L0..L3；重拍新会话不改原图身份。
3. 相机/AF/AE/AWB、实际距离、背景/光照、全部specimen、数量档和朝向填[既有CSV](../fastener-collection-log-template.csv)；示例行交付前删除。
4. 每帧重新摆放，只拍一张该布局；会话编号/标尺/标签置于对照图，不让标签污染训练画面。
5. 首批交付原PNG目录+实际采集表行+实物对照表+原文件SHA清单；WC再做manifest/GT/ROI和审计，NC不替签标签正确。
6. 原PNG交付后不改名/重编码/裁剪；追加/补拍走新会话，记录接收人/交付时间/补采原因。

## 返板才填的表

| 定标对象 | 必须采样 | 现在不得填成实测的字段 |
|---|---|---|
| 距离 | 40/50/60/70/80cm原帧和尺标 | mm/px、最小垫圈像素尺寸、视野、选定理由 |
| 背景/光照 | 三种背景及L0–L3，保留分裂/合并/漏框/多框 | 支持条件、曝光/对焦/AWB实际设置 |
| 间距 | 0.5D/1D/2D/4D，写明D对应实物尺寸 | 最小支持间距及各档独立布局数 |
| 朝向/数量 | 每类朝向、1/3–5/8–10数量档、独立test空场景 | 每格实际原帧数量、真实覆盖缺口 |

64×64及10件策略按既有契约；≥128px、≥600帧、每格≥10帧等为既有采集建议，未实测/评审不转成验收硬门限。
完整原帧依[N03执行单](n03-custom-return-runbook-2026-10-14.md)验证后定标；base诊断/采集与custom集成分别留证，不能相互代签。
