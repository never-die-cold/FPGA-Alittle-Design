# NC工业与故障验收执行矩阵

2026-10-14；依据[三人清单N09–N12](../project-closeout-three-person-checklist.md)、[C03 §8](../contracts/coprocessor-integration-v0.md)及[NC已确认C04](../contracts/vision-live-semantics.md)。
本单是离板准备：以下实机用例全部未测，不以FILE/MOCK回归勾选通过。默认工单bolt=2/nut=2/washer=2；变更须记录当轮expected与配置回执。
进入条件：当前版本N01–N03通过、正式模型/集成包及真实LIVE交付。软件诊断可先演练，但结果标PS/FP32/PROTOTYPE。

|---|---|---|

| I02 | 保持有效视频，移走全部零件 | CHECK_FAIL，实测actual三类为0；不能当NO_VIDEO |

| I04 | 增加1螺栓 | CHECK_FAIL，extra.bolt=1 |

| I08 | 低分或未知类别 | RECHECK；未知类不硬归入三类，分数语义按当前模型契约 |

## 轮次与恢复（N11）

| ID | 输入/动作 | 必须观察的结果 |
|---|---|---|
| F01 | 不触发，重复视频/自动轮询 | 不新增合法批次 |
| F02 | 同一请求因网络失败重试 | 按已评审重试键复用/冲突拒绝；请求幂等未实现，现阶段不得签通过 |
| F03 | 同session/check结果重放及EXE重启 | 不重复记录；跨进程持久去重未实现，独立待修 |
| F04 | 工单改变后注入旧config结果 | 立即撤框；新配置确认前不记录或放行；软件config编号不替代硬件回执 |
| F05 | 超过max_age、连续HTTP失败3次 | 撤框/等待态；不静默显示旧判定，不新增有效批次 |
| F06 | 服务/板卡重启、Overlay重载、换源 | 新session、旧结果失效、重握手/真实配置确认后恢复 |
| F07 | 无新帧、断源、DMA/CNN错误、超时 | 拒绝生成通过结果；错误通路按C03，不伪造CHECK_PASS或合法批次 |
| F08 | 错轮/篡改/缺失的权威产物 | 快照读取拒绝，不能用UVC截图补成“同帧证据”；真实快照查看未实现 |
| F09 | 未知字段、非法框/ID/类别、损坏JSON | 服务/EXE严格拒绝；无静默降级或有效记录 |
| F10 | 程序退出、存储失败、恢复失败 | 原始主失败与恢复失败分开；DMA停止未知保持缓冲/进程，沿[N03执行单](n03-custom-return-runbook-2026-10-14.md) |

每例独立记录：case_id、来源/后端、源码/bit/hwh/模型/配置/软件SHA、boot/session/check/capture/config、工单/GT、输入原帧/ROI、原始报文/decision、界面/记录/CSV、动作时序、恢复、退出码、判定/复核人。
所有case结束后确认正常基线恢复；一次FAIL必须保留，修复包另开记录复验，不覆盖旧日志。

## 测量口径（N12）

| 指标 | 原始数据及分母 |
|---|---|
| 定位漏报/多框/分裂/合并 | 人工GT与预测匹配规则/阈值预先写明；保存逐帧配对，不只给平均准确率 |
| 分类 | 同目标ID的GT/预测类别、模型/阈值；定位遗漏与未知类分开，输出逐类混淆/样本量 |
| 工单错误放行/错误拒绝 | 逐轮GT与最终decision；可判定合格/不合格轮次分别作分母，RECHECK单列，不混入普通FAIL |
| 复检率 | 唯一有效检查中的RECHECK轮数/唯一有效检查数；来源、期间、支持条件均注明 |
| 延迟 | capture等待/复制、PS定位/ROI、DMA/CNN、核判定、服务/网络、EXE处理、UVC显示分别记录；跨设备无共同钟不直接相减 |
| ARM与CNN | 相同capture/ROI与模型参数/阈值；INT8逐层/最终值对黄金，FP32差异另报；排除加载/IO须明确 |
| 时序/资源 | 集成实现报告，注明器件/工具/约束与统计范围；控制器OOC不等于全系统 |

预先登记输入集、预热/采样次数、持续时长、负载与成功/失败定义；保留所有样本，统计median/P95/max及错误数。缺测用“未测”，分母为0不填0%或宣称无误报。
剩余未实现：Q5显示/导出一致性[#75](https://github.com/never-die-cold/FPGA-Alittle-Design/issues/75)、请求幂等/持久去重/真实快照、正式模型/CNN集成/核判定与真实LIVE。
