### 1.1 先分清"AMD 赛道"的三层结构

FPGA 创新设计赛道由多家企业出题，2026 年共 7 家企业 / 24 项一级选题 / 139 页选题指南（AMD / 紫光同创 / 安路 / 高云 / 易灵思 / 复旦微 / 中科亿海微）。AMD 一家的选题方向：

| 年份（届） | AMD 赛道结构 |
|:---|:---|
| 2026（第 9 届） | ① RTL/HLS 本地智能体设计赛道 ② 具身智能赛道（AI PC + FPGA） ③ **自主选题赛道（初级组 / 高级组）← 本项目所在** |
| 2025（第 8 届） | AMD 命题式基础赛道（仓库命名 `hlstrack2025_*`）：初赛为 Vitis HLS 算子优化三题（SHA-256 / LZ4 / Cholesky），决赛为延伸设计题 |
| 2024（第 7 届） | 已有 AMD 命题式基础赛道（有选手连续参加 2024、2025 两届） |

> 结论：搜索"往届 AMD 获奖作品"时，2024–2025 大量命中是 HLS 命题赛道，与本项目"自主选题 + 自研 RTL"不同；自主选题赛道公开开源作品较少（见 1.3）。

1. 权重导向：30 分创新性靠"自研 RISC-V 三级流水 + 视觉 SoC"的芯片设计含量；15 分大模型协作与技能包、15 分文档与可复现——我们现有的 `llm_log`（含真实纠错轨迹）、`skill/`、目录对照说明正是对着这 30 分建设的，继续保持。

### 2.2 逐题说明

#### AMD

**1) RTL/HLS 本地智能体设计赛道**
- 做什么：用本地部署的开源大模型 + 自研智能体（Agent）+ 技能包，在 AMD GPU 上自动生成 Verilog / Vitis HLS C++ 代码，通过 Vivado/Vitis 工具链反馈迭代，提高硬件代码生成通过率
- 技术要求：本地大模型部署与量化（32GB 单卡显存约束）、Agent 设计（重试/回退/上下文管理）、Docker 容器化（断网沙箱运行）、熟悉 Vivado/Vitis 2025.2 工具链
- 达标目标：在官方隐藏题集上通过「可编译→仿真通过→可综合」分级判定，报告 pass@1/pass@5；评分权重：通过率 30 + 相对裸跑基线增益 40 + 效率 10 + 工程质量 20
- 难度：★★★★★ 最高。考察的是 AI 工程能力而非传统 FPGA 设计，适合有 LLM/Agent 经验的团队

**2) 具身智能赛道**
- 做什么：用 AMD Ryzen AI PC（上位机）+ AMD FPGA/Zynq 板卡搭建机器人/视觉检测等系统，完成感知—决策—控制—执行的完整物理闭环（如机械臂抓取、移动机器人避障、视觉分拣）
- 技术要求：端侧 AI 推理（ROCm 7.14+）、FPGA 实时控制（电机驱动/高速传感/10G 以太网）、双端通信与时间同步、机械结构搭建
- 达标目标：真实硬件跑通闭环，必须报告 5 类核心指标（闭环成功率、端到端延迟 P50/P95/P99、AI 效果、FPGA 量化贡献、通信性能）+ 至少 2 项场景指标；评分：系统完整度 20 + AI 能力 20 + FPGA 设计 25 + 协同 20 + 创新 15
- 难度：★★★★★ 最高。软硬件+机械+AI 全栈，工作量最大

**3) 自主选题赛道（初级组/高级组）**
- 做什么：任意完整 FPGA 作品，方向不限；初级组（大一~大三）推荐用 PYNQ，高级组（大四/硕士）不限器件
- 技术要求：基础 FPGA 设计能力；强制要求提交与大模型协作的记录和可复用"技能包"
- 达标目标：创新性与应用价值 30 分占最高权重，加上性能资源 20、功能正确 20、大模型协作 15、文档可复现 15
- 难度：★★★ 中等。自由度高，难度取决于自选题目

#### 安路

**1) HDMI 多媒体播放系统**（EG4S20，最小器件 19.6K LUT）
- 做什么：FPGA 从 TF 卡读 BMP 图片→SDRAM 缓存→HDMI 输出，加音频输出、按键交互
- 技术要求：BMP 解析、SDRAM 控制器、HDMI 时序、音频输出；不允许用任何外部处理器
- 达标目标：基础功能（稳定显示+音频）+ 加分项（字幕叠加、转场特效、缩放、参数调节、音频频谱可视化）
- 难度：★★☆ 较低。最经典的入门级赛题

**2) 实时数字图像处理系统**（PH1P35 + MIPI 摄像头）
- 做什么：MIPI 摄像头采集→FPGA 图像处理（边缘检测/二值化等）→HDMI 实时显示 + OSD 叠加（含"安路"Logo）
- 技术要求：MIPI CSI 接口、图像流水线、HDMI 显示、OSD
- 达标目标：4 项基础要求必做；加分项含目标跟踪、延迟可视化、自动白平衡等
- 难度：★★★ 中等。官方提供 3 个样例例程，路径清晰

**3) 图像采集压缩与智能预处理加速系统**（安路 PH1A90 + 瑞芯微 RK3576 异构板）
- 做什么：FPGA 做采集/预处理/压缩，RK3576 NPU 做 AI 检测，全链路机器视觉系统
- 技术要求：MIPI 采集 IP、3 种硬件预处理算法、JPEG/LZ77 硬件压缩、MIPI/PCIe 高速互通、NPU 模型部署——6 项硬性任务缺一不可
- 达标目标：给出帧率/延迟/资源/压缩率/推理耗时量化报告；分简单/中/高三级落地标准（如 60fps 无丢帧、识别准确率 80%~90%+）
- 难度：★★★★★ 高。双芯片异构，环节最多，且是"全做不全不得分"的硬性清单

**4) 飞龙虎系列 SoC 智能工业应用**（DR1M90G：ARM+FPGA+NPU）
- 做什么：工业场景系统（多轴伺服/状态监测/视觉分拣/协议网关/故障诊断五选一方向）
- 技术要求：PL 实时控制 + PS Linux + AXI 交互 + NPU 推理 + CAN/RS485 总线，6 项硬性必做
- 达标目标：量化测试报告（控制精度、采集延迟、AI 耗时、总线稳定性）；简单/中/高三级指标
- 难度：★★★★☆ 较高。全栈嵌入式 + 工业总线

**5) 自主命题**：不限板卡，按创新性/趣味性/实用性评判。难度自定。

#### 复旦微

**唯一赛道：基于 FMQL30TAI"悟净"FPAI 开发板的开放选题**
- 做什么：自选场景（智能视觉/机器人/语音/智慧交通/射频/AI-RAN），在国产 FPAI 芯片（4 核 CPU + 8TOPS NPU + 125K LUT FPGA + 4K VPU）上做 AI+FPGA 异构系统
- 技术要求：≥1 个 AI 模型完成转换/量化/上板推理（Icraft 工具链）；≥1 项 FPGA 开发（接口/预处理/自定义算子）；形成端到端闭环；鼓励用大模型辅助开发并记录
- 达标目标：CPU/NPU/FPGA 分工清晰 + 性能数据对比；评分按方案设计、实现、性能、文档、AI 工具效率加分
- 难度：★★★★☆ 较高。要同时碰 NPU 部署和 FPGA，但题目开放、不卡硬指标

#### 高云

**1) 倒立摆实时姿态控制系统**（J280 套件，板卡+机械机构都有）
- 做什么：FPGA 采集角度传感器+编码器，算控制量输出 PWM，让倒立摆起摆并稳定直立
- 技术要求：传感器采集、控制算法（PID/LQR 等）硬件实现、PWM 电机驱动
- 达标目标：起摆→稳定直立→抗轻微推力；拓展：定点位置移动中保持平衡
- 难度：★★★ 中等。算法是重点，机械平台现成，不需要自己搭

**2) 实时多音色合成电子乐器**（Sipeed Tang 系列）
- 做什么：自研交互（触摸/手势）+ FPGA 纯硬件音频合成（波表/FM/物理建模），I2S 输出
- 技术要求：音频合成算法硬件化、复音架构、低延迟设计（≤10ms，拓展 ≤5ms）
- 达标目标：≥4 复音、≥2 维交互、逐样本实时合成（严禁播放预录音频）；拓展 32 复音/效果器/可视化
- 难度：★★★☆ 中高。创意性强、演示效果好，音频 DSP 是门槛

**3) 具身智能机器人**（小梅哥 ACG720/750 等）
- 做什么：FPGA（+软核 CPU）做机器人：摄像头+IMU 感知、电机闭环控制、超声/TOF 避障、自主导航
- 技术要求：多传感器接入、运动控制、避障导航算法；拓展可用 RK3588 做视觉识别
- 达标目标：起点到终点自主导航+避障；评分：FPGA 实时感知控制 40% + 稳定性 25% + 导航 20% + 创新 10% + AI 5%
- 难度：★★★★☆ 较高。要攒一台能跑的小车

**4) 开放题**：体现 FPGA 不可替代性（不用 MCU）。难度自定。

#### 易灵思

**1) AI 实时绘画——风格化视频渲染**（Ti60F225）
- 做什么：MIPI 摄像头→FPGA 硬件加速轻量风格迁移网络（梵高/浮世绘等）→HDMI 输出，RISC-V 软核管控制
- 技术要求：神经网络硬件加速器（卷积/归一化硬件化）、MIPI+DDR+HDMI 全链路、RISC-V 驱动
- 达标目标：640×480 ≥15fps；高阶：多风格 <100ms 热切换、720p@30fps、自研 <500KB 参数网络
- 难度：★★★★★ 高。NN 加速器是硬核挑战

**2) RISC-V+FPGA 2D 渲染加速引擎**
- 做什么：FPGA 实现 BitBlt 引擎（块拷贝/填充），RISC-V 跑游戏逻辑，软硬件渲染帧率对比
- 技术要求：AXI 总线、突发传输、VGA/HDMI 时序、双缓冲；高阶 Alpha 混合+Color Keying
- 达标目标：640×480@60Hz + 软硬帧率对比 Demo；高阶弹幕游戏 60fps 下同屏精灵数极限
- 难度：★★★☆ 中高。结构清晰、趣味性强

**3) 多模态 AI 智能终端**（跌倒检测/智能空调/入侵报警）
- 做什么：摄像头+红外测温 MLX90640+温湿度 SHT30 多传感器融合，TinyML 推理做事件检测
- 技术要求：多路 I2C/MIPI 采集、RISC-V+TinyML、多模态融合决策
- 达标目标：完成 3 大任务（采集/AI 决策/拓展 2 项），本地报警+显示
- 难度：★★★★☆ 较高

**4) 实时图像边缘检测**（VF-Ti60F225）
- 做什么：摄像头→灰度化→中值滤波→Sobel→HDMI 分屏显示，全流水线"零延迟"
- 技术要求：摄像头驱动、行缓存、Sobel 流水线、HDMI 时序；高阶 Canny、DDR 帧缓存
- 达标目标：640×480 稳定采集+边缘检测+分屏显示；官方明示基础约 3-4 周、含高阶 5-6 周
- 难度：★★☆ 较低。文档最详细、路径最清晰，适合新手

**5) 自由选题**：不限方向，要求 FPGA 承担核心功能（不能只做转接板）。难度自定。

#### 紫光同创

**1) RISC-V CPU 设计**（盘古系列板卡）
- 做什么：Verilog 实现 RV32I CPU：≥3 级流水线、UART/GPIO 外设，CoreMark 跑分
- 技术要求：处理器架构设计（流水线/冲突/分支）、Cache、分支预测（高阶）；高阶可挂 AI 加速单元
- 达标目标：CoreMark/MHz 越高越好 + 资源效率（CoreMark/LUTs）+ 最高频率；运行 ≥10 秒
- 难度：★★★★☆ 较高。体系结构硬核，但评测客观明确

**2) 任意角度图像畸变矫正**
- 做什么：FPGA 实现相机畸变矫正（径向/切向坐标映射+双线性插值），实时视频流矫正
- 技术要求：图像采集显示链路、坐标映射定点化、重采样；高阶 IMU 动态矫正
- 达标目标：1080P@30/60fps 实时、直线度误差小、端到端延迟低、资源少；现场可能要求换角度/图卡
- 难度：★★★☆ 中高

**3) ADAS 高级辅助驾驶系统**
- 做什么：FPGA(+ARM/RISC-V)做车道识别、红绿灯识别、行人检测，按官方给的视频场景（U盘现场提供）模拟变道/刹车/报警
- 技术要求：图像处理流水线、软硬协同通信（PCIe）、AI 模型部署（高阶）
- 达标目标：现场 4 类场景测试（红绿灯启停、虚/实线变道、导航、行人刹车）+ 1080P 演示视频
- 难度：★★★★☆ 较高

**4) SOPC 开放题**：基于 Kosmo-2 SoC 板自主命题。难度自定。

#### 中科亿海微（纯软件/EDA 题，无需硬件）

**1) 基于以太网 MAC 的 AFDX 航电总线端系统**
- 做什么：FPGA 实现 AFDX（ARINC 664 Part7）端系统：UDP/IP、虚拟链路、发送调度、SNMP、615A 加卸载
- 技术要求：以太网 MAC、UDP/IP 协议栈、AFDX 规范理解、仿真验证
- 达标目标：100Mbps、端到端时延 <1-2ms、支持 128 发/4096 收 VL；评分：代码仿真 40% + 文档 20% + 测试报告 20% + 指标 20%
- 难度：★★★★☆ 较高。协议复杂，但只需仿真、不用调硬件

**2) Yosys PMUX 结构优化（EDA 算法题）**
- 做什么：在开源 Yosys 框架里写 Tcl 插件，优化 PMUX 电路结构以减少面积
- 技术要求：C++/Tcl 开发、逻辑综合算法、EQY 形式等价验证
- 达标目标：单元数缩减 ≥10%（20% 满分）、千级节点 ≤60s/≤2GB、全部用例等价性通过（不等价直接 0 分）
- 难度：★★★★☆ 高。最特殊的一题——纯 EDA 算法，适合计算机/算法强的队伍，指标极度量化

### 2.3 难度横向对比与选题建议

| 难度档位 | 选题 |
|---|---|
| ★★☆ 入门友好 | 安路选题一（HDMI 播放器）、易灵思赛题四（边缘检测） |
| ★★★ 中等 | 高云选题一（倒立摆）、AMD 自主选题、紫光畸变矫正、易灵思 2D 引擎、各厂开放题 |
| ★★★★ 较高 | 安路选题四（工业 SoC）、复旦微、高云选题三（机器人）、紫光 RISC-V CPU / ADAS、中科亿海微两题、易灵思赛题三 |
| ★★★★★ 最难 | AMD RTL/HLS 智能体、AMD 具身智能、安路选题三（双芯片异构）、易灵思赛题一（风格化 AI 加速） |

选择时建议考虑三点：① 团队强项——偏 AI/软件选 AMD 智能体、复旦微、易灵思多模态；偏 RTL/硬件选紫光 CPU、易灵思边缘检测、安路图像处理；偏控制算法选高云倒立摆。② 是否需要攒硬件——中科亿海微纯仿真零硬件成本，高云/AMD 具身智能需要机械平台。③ 评分客观性——中科亿海微、紫光 CPU（CoreMark）、AMD 智能体（通过率）指标最量化，不容易因评委主观因素失分。
