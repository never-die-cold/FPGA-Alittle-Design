## 2. 真题题型清单（2019–2025 真题归纳）

| 题型 | 考点 | 真题实例 | 对应 HDLBits 题集 |
|:---|:---|:---|:---|
| 计数器链/数字钟 | 多模计数器级联（10/12/24/60 进制）、进位与清零、数码管扫描 | 2024 数字钟（counter10/12/24/60 级联 + top） | Sequential Logic 计数器部分 |
| 状态机（FSM） | Moore/Mealy、按键输入、多状态定时切换 | 2023 电梯控制、2023 序列检测（两种风格）、2025 交通灯（含行人按键） | FSM / FSM (组合两段式) |
| 运算模块 | BCD 加法、补码转换、带符号累加、`function` 使用 | 2020 BCD 加法器、补码转换、带符号累加器 | Verilog Language 运算/过程块 |
| 综合计时逻辑 | 输入约束（如投币金额）+ 剩余计数 + 多阈值状态输出 | 2024 投币游戏计数 game_count | 综合（计数器 + FSM） |

**出题规律**：题干给功能描述，要求 1–4 个模块 + 自写 testbench，**波形正确**是唯一硬验收；组合逻辑 + 时序逻辑混编，难度约 HDLBits 中档。

## 3. 备赛节奏（嵌进各里程碑，固定时段：**周日下午**）

- **每周日下午固定 1.5h**：1 道限时真题（或 HDLBits 专题），做完三人互评波形
- **工作日不挤占开发时间**：HDLBits 每天 5 题照旧（见 prep_checklist）
- **M1 收尾做第一次全真模拟**：断网 + 只开本地 Vivado + 队友当监考验收波形
- **决赛前（11 月）**：五年真题全部覆盖，每人所有题型至少独立做过一遍

## 4. 全真模拟流程（模拟考场实况）

1. **环境**：关网（含手机热点）、只开本地 Vivado、计时 90 分钟
2. **出题**：从 MrYanYe 仓库抽一道没做过的真题 PDF（U 盘提前拷好离线资料）
3. **验收**：做题人跑出波形后叫"监考"（轮值的队友），监考只看波形打勾，**不提示错误**；被要求时口头解释代码
4. **复盘 15 分钟**：超时/波形 bug 的根因记一条 `report/llm_log/`（若涉及 AI 协作则按模板，否则简单记进本文件进度表备注）
5. **轮换**：下次换出题人与监考，保证三人都当过监考
