# 紧固件采集交接包：编号规则、采集表与验收矩阵（W01）

> 是什么：W01 给 NC 的采集执行件——实物/会话/帧三层编号规则、逐会话采集表模板、
> 覆盖矩阵与数据验收矩阵；配合[采集规程](fastener-data-collection-protocol.md)（采集方法）与
> [数据审计](fastener-dataset-audit.md)（仓库内工具）使用，不替代二者的规则。
> 给谁看：never-die-cold（N04/N05 执行与交付）、watercopper（W02/W03 接收与标注）。
> 状态：2026-10-10 首版，待 NC 确认；机位/光照/背景定标（N04）完成后回填 ⚠️ 项。
> 完成标准（W01）：**采集覆盖与数据拆分可执行；图像原始字节和采集版本可追溯**。

## 1. 编号规则（三层 + 实物）

| 层 | 编号 | 规则 | 示例 |
|:---|:---|:---|:---|
| 会话 | session_id | `sess-YYYYMMDD-HHMM-<L0..L3>-<bg>`，小写、禁空格；同日多会话用 HHMM 区分；**重拍＝新会话，不覆盖** | `sess-20261012-0930-L0-wood` |
| 帧 | frame_id | `frame_00001` 五位主名，会话内递增；同号可跨会话，帧身份 = 会话 + 编号 | `frame_00007` |
| 帧内目标 | obj_id | 帧内唯一，从 1 递增，与 GT 行数一致；**不能代替实物编号** | `1` |
| 实物 | specimen_id | `类别缩写-小写字母`：`bolt-a…` `nut-a…` `washer-a…`；同实物跨会话复用 | `bolt-a` |

- 实物标签贴在**收纳格 / 卡纸**上，不贴金属件本身（贴纸会进画面影响像素）；标签文字与 specimen_id 一致。
- 首会话交付**实物对照表**（类别、个体、标签位置、整体照片一张）；后续会话只引用编号，不重编号。
- **数据拆分按会话整体划分**（采集规程 §4.2 硬规则）：同一会话只进一个 split；test 会话预留**独立实物**（如 `bolt-c` 只进 test）、独立日期、独立布置，避免相邻帧与实物泄漏。

## 2. 采集表（逐会话一行）

模板：[fastener-collection-log-template.csv](fastener-collection-log-template.csv)（表头固定，值可中文；示例行交付前删除）。

| 列 | 说明 |
|:---|:---|
| session_id | §1 规则；目录名同此 |
| date / operator | 采集日期 / 操作者 |
| split | train / val / test（会话级；写建议值，最终由 W02 确认） |
| camera / manual_settings | 相机型号 + AF/AE/AWB 是否手动改动；**任何手动改动必填**，无改动写 `default`——这是“采集版本”的一部分 |
| distance_cm | N04 定标选定档位（40–80 cm） |
| light / bg | L0–L3 / dark·gray·wood |
| specimens | 本会话出现的实物编号，逗号分隔（`bolt-a,nut-a`） |
| frame_count | 本会话帧数 |
| count_tiers | 每帧件数档（`1` / `3-5` / `8-10`） |
| classes | 覆盖类别 |
| orientation_notes | 朝向覆盖说明（螺栓：轴向/斜置/头朝上；螺母垫圈：正扣/斜扣） |
| notes | 异常、补采、条件偏离说明 |

- **交付节奏（先交先标）**：每完成一个会话即交 WC——原帧目录 + 本会话采集表行 +（新实物）对照表；不等整批采完。
- 落地位置：`data/datasets/fastener-v1/raw/<session_id>/frame_*.png`（采集规程 §4.3 布局）；
  `manifest.csv` / `gt/` / `crops/` 由 WC 在 W02 生成，采集侧不写。
- 帧文件**一经落盘不得再编辑/转换/改名**（重编码、裁剪、EXIF 改动都会改变字节，破坏追溯）；需要修正只能补采新会话。

## 3. 覆盖矩阵（逐格计数，目标见采集规程 §4.1）

每格 ≥10 帧；计数 = 帧数。空缺格 = 覆盖缺口 → 由 W02 首审回传补采清单（先补缺口再补量）。

| 朝向 \ 光照 | L0 | L1 | L2 | L3 |
|:---|:---|:---|:---|:---|
| bolt 轴向 | | | | |
| bolt 斜置 | | | | |
| bolt 头朝上 | | | | |
| nut 正扣 | | | | |
| nut 斜扣 | | | | |
| washer（正扣/斜扣） | | | | |
| 空场景（**仅 test**，建议 ≥3/格） | | | | |

- 总量：首轮 ≥600 帧（⚠️ 建议值，视首轮基线精度加采）；单帧最多 10 个目标；
  每帧重新随机摆放，同一摆放只拍 1 帧（防近似重复）。
- 背景：默认背景按采集规程 §3.2 实测选定。某条件（如 L3 自然窗光）不可用时，在覆盖矩阵与采集表中**登记缺口**，
  由 W02 决定补采或收缩支持条件——不得无声省略，也不得事后伪造补数。

## 4. 数据验收矩阵（A1–A8）

工具入口：`py sim/vision/audit_fastener_dataset.py <数据根> <报告.json> --source-kind DECLARED_PYNQ --max-targets 10`
（报告须为新文件；PASS = `DATASET_STRUCTURE_AUDIT`；语义与限制见[数据审计](fastener-dataset-audit.md)）。

| # | 检查项 | 方法 | 通过标准 | 不通过处理 |
|:---|:---|:---|:---|:---|
| A1 | 结构与格式 | 审计工具 | PASS；清单/文件/PNG(1280×720×3 uint8 BGR) 一致；无格式拒绝 | 修正清单；字节或尺寸错误只能补采 |
| A2 | 集合泄漏 | 审计工具 | 无跨 split 泄漏（同会话/同实物/同字节/同像素） | 重划 split 或剔除；实物泄漏须重采 |
| A3 | 覆盖 | 审计报告 + §3 矩阵 | 每格 ≥10 帧；`missing_classes` 为空；缺口列清单 | 补采（先补缺口） |
| A4 | 实物隔离 | 审计 `all_specimen_ids_present` + 对照表 | 全部目标有 specimen_id 且与对照表一致 | 补编号/补录；无法对应 → 降级为结构性数据 |
| A5 | 原始字节追溯 | 审计报告内 CSV/PNG/解码像素 SHA256 + §2 流程 | 哈希入报告；帧文件与采集落盘字节一致（无再加工） | 重新导出或补采；改动过的帧不得入正式集 |
| A6 | 采集版本追溯 | 采集表 §2 | 逐会话 camera/manual_settings/distance/light/bg 完整 | 补录说明；无法确认设置的会话降级 |
| A7 | 人工复核 | 每会话抽 10 帧 + GT 抽检 | 无运动模糊/失焦/过曝；GT 与画面一致 | 重拍该会话；GT 错误由 W02 修正 |
| A8 | 空场景 | 审计空帧规则 | 只在 test、空标记行格式合规 | 移 split / 补录 |

- A1–A3 由工具出判决（可复算）；A4–A8 需人工在报告上签署，**“脚本打印 PASS”不替代人工复核**。
- 来源标识三档（TEST_FIXTURE / PUBLIC / DECLARED_PYNQ）显式选择：正式采集用 `DECLARED_PYNQ`；
  报告中 `capture_origin_authenticated` / `label_accuracy_verified` 恒为 false 的口径在材料中原样保留（工具不能证明来源真实性）。
- 审计只覆盖结构与精确重复；GT 对照、真实标签质量、朝向统计、相似帧检测属 W02 人工/后续实现范围。
