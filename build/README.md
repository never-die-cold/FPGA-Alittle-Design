# build —— 可复现构建

Vivado 构建脚本与综合/实现报告，保证工程可由他人从零复现。

## 规划内容

- `build.tcl`：一键构建脚本（创建工程 → 添加源码 → 综合 → 实现 → 生成 bitstream）
- `constraints/`：时序约束 XDC 与引脚约束
- `reports/`：综合与实现报告归档（资源占用、Fmax、WNS）

## 约定

- 工具版本：Vivado 2026.1（推荐）或 2025.2，版本写入报告
- 每次里程碑打 tag，并归档当次构建报告
- 报告数据与 `README.md` 指标表、`report/` 设计报告保持一致
